# Exploratory Data Analysis (EDA)

This directory contains all artifacts from Phase 3: Enterprise Exploratory Data Analysis.

## Directory Structure
- `dataset_overview.md` - High-level metrics.
- `data_quality_analysis.md` - Validation of Phase 1 cleaning.
- `univariate_analysis.md` - Individual feature distributions.
- `target_analysis.md` - Target variable (`SLA_Breached`) definition and baseline.
- `bivariate_analysis.md` - Feature-target relationships.
- `multivariate_analysis.md` - Multi-feature interactions.
- `business_analysis.md` - KPI analytics.
- `feature_insights.md` - Predictive value mapping.
- `model_readiness.md` - Model algorithm evaluations.
- `executive_summary.md` - Top insights.
- `business_recommendations.md` - Strategic changes.
- `ml_recommendations.md` - Technical changes.
- `visualization_index.md` - Chart definitions.
- **`eda_report.md`** - Master report and certification.
