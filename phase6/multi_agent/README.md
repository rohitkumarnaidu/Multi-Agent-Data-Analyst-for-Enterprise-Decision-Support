# Multi-Agent Core Architecture

## Overview
This directory contains the Phase 6B Multi-Agent Core, powered by LangGraph. It provides the central orchestration for the Datasphere 26 Enterprise Platform, routing intents to specialized sub-agents.

## Artifacts
1. **Multi_Agent_Report.md**: Complete executive summary of the Multi-Agent engine.
2. **LangGraph_Architecture.md**: Technical breakdown of the `StateGraph`.
3. **Agent_Registry.md**: Explanation of the dynamic injection and agent discovery mechanisms.
4. **Agent_Workflow.md**: Node-to-node workflow descriptions.
5. **Execution_Flow.md**: Traceability and state management logic.
6. **Testing_Report.md**: Results of the LangGraph test harness.
7. **Developer_Guide.md**: How to build and register new agents.
8. **Implementation_Summary.md**: Phase 6B deliverables summary.

*Note: RAG, ChromaDB, Memory, Frontend, and Authentication are EXPLICITLY out of scope for this module.*
